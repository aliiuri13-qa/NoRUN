## Brand & Style

The design system establishes a high-performance, dark-mode-first aesthetic engineered for fast-paced, high-distraction environments such as weight rooms and training facilities. It bridges technical precision with athletic kinetic energy, projecting focus, durability, and momentum.

### Personality & Tone
- **Focused & Uncompromising:** Eliminates visual clutter so athletes execute and log sets with zero friction.
- **Electrifying & Athletic:** Uses electric azure and hyper-cyan highlights against abyssal blues to communicate vital signals, set completion, and records.
- **Ergonomic & Resilient:** Emphasizes massive single-handed touch zones, clear visual affordances under gym glare, and immediate legibility from arm’s length.

### Visual Style
The interface blends **Deep High-Contrast Minimalist Surfaces** with **Technical Luminescence**:
- Pitch-black and dark obsidian base layers minimize OLED battery consumption while ensuring maximum visual contrast.
- Subtle glass-like structural borders (1px translucent boundaries) delineate functional workout zones without visual weight.
- Punchy, high-saturation electric cyan and cobalt accents drive eye movement directly to actionable states, rest timers, and weight increments.

## Colors

The palette leverages high-luminance active tones anchored by deep, noise-free navy foundations. It is optimized strictly for OLED clarity and immediate comprehension in bright overhead or dim gym environments.

### Canvas & Surfaces
- **Canvas Base (`#0B111E`):** Pure background canvas; anchors visual weight and recedes beneath components.
- **Surface Elevation 1 (`#111A2E`):** Default card background, set container, and inactive tracker cells.
- **Surface Elevation 2 (`#1A253D`):** Elevated modals, input steppers, and floating bottom sheets.
- **Surface Elevation 3 (`#233354`):** Active set row highlights, hover states, and pressed states.

### Accents & Performance Cues
- **Primary Athletic Cyan (`#00D2FF`):** Main interactive focal point. Used for live active timers, PR (personal record) badges, progress bars, and glowing touch targets.
- **Secondary Electric Blue (`#2563EB`):** Solid CTA backgrounds ("Start Workout", "Finish Routine"), selected toggle chips, and primary action fills.
- **Interactive Light Blue (`#3B82F6`):** Secondary interactive triggers, links, and active iconography.
- **Success & PR Green (`#10B981`):** Completed set checks, successful progression markers, and streak validations.
- **Warning & Rest Amber (`#F59E0B`):** Rest countdown timer alerts and warm-up set designations.
- **Destructive Crimson (`#EF4444`):** Failed sets, workout cancellation, or rep dropoffs.

### Typography & Border Contrasts
- **Text High-Emphasis (`#F8FAFC`):** Primary metric numerals, exercise titles, and active inputs.
- **Text Medium-Emphasis (`#94A3B8`):** Muscle group tags, previous set metrics, labels, and inactive tab bars.
- **Text Low-Emphasis (`#475569`):** Ghost plate values, completed subtext, and structural meta-units.
- **Subtle Structural Border (`rgba(255, 255, 255, 0.08)`): Standard boundary line for cards and input containers.
- **Active Accent Border (`rgba(0, 210, 255, 0.40)`): Focus state and live set recording container outline.

## Typography

The typography system pairs **Space Grotesk** for energetic, modern headlines with **Plus Jakarta Sans** for ergonomic legibility in logs, and **JetBrains Mono** for fixed-width numerical readouts (weights, reps, RPE, countdown timers).

### Rules of Usage
- **Tabular Alignment:** All numerals detailing weight (`kg`/`lbs`), repetitions, and countdown timers must leverage monospace tabular sizing (`JetBrains Mono` or `font-variant-numeric: tabular-nums`) to prevent layout shifts during live counting.
- **Metric Contrast:** Metric numerical values (`metric-value-lg`) must always be rendered in high-emphasis white (`#F8FAFC`) with unit suffixes (`kg`, `reps`) rendered smaller in medium-emphasis cyan or slate (`#94A3B8`).
- **Uppercase Overlines:** Category headers, set type labels (`WARMUP`, `DROPSET`, `WORKING`), and table columns must use `label-caps` in uppercase styling with deliberate tracking for quick scanning.

## Layout & Spacing

The layout is built for one-handed thumb interaction within vertical mobile viewports, applying an 8-point base grid (with a 4-point micro-step for compact set grids).

### Grid & Ergonomic Philosophy
- **Thumb Zone Anchor:** All critical actions (Log Set, Rest Next, Finish Workout, Plate Math) are locked to the bottom 35% of the mobile screen.
- **Mobile Grid:** Single-column layout fluid across viewport widths, using `16px` outer margins (`margin`) and `12px` inter-column gutters (`gutter-mobile`) inside set comparison tables.
- **Compact Vertical Density:** Set tables utilize tighter vertical spacing (`space-sm` and `space-md`) to ensure that at least three active exercises and their full history remain visible above the software keyboard.
- **Hit Targets:** Minimum clickable surface area for tap targets is strictly `48px x 48px` (`min-h-[48px]`), accommodating shaking or chalked hands during strenuous lifts.

## Elevation & Depth

Visual hierarchy uses physical tonal stacking paired with subtle luminescent borders rather than heavy traditional drop shadows, maintaining crisp contrast on dark displays.

### Elevation Hierarchy
- **Level 0 (Floor Canvas `#0B111E`):** Base screen background; flush with the device bezel.
- **Level 1 (Structural Containers `#111A2E`):** Exercise cards and grouped set histories. Outlined with a continuous 1px border of `rgba(255, 255, 255, 0.08)`.
- **Level 2 (Active Focus & Steppers `#1A253D`):** Active workout inputs and counter badges. Framed with a 1px border of `rgba(255, 255, 255, 0.14)`.
- **Level 3 (Overlays & Sheets `#1E2B48`):** Rest timer overlays, RPE picker trays, and plate calculators. Supported by an ambient drop shadow: `0 12px 32px -4px rgba(0, 0, 0, 0.6)`.

### Active Glow
Active or in-progress states (such as a currently running rest timer or a selected input field) receive an electric cyan ambient glow:
`box-shadow: 0 0 16px -2px rgba(0, 210, 255, 0.25), inset 0 0 0 1px #00D2FF`.

## Shapes

The design system utilizes modern, organic curvatures balancing modern athletic hardware with approachable interface mechanics.

- **Primary Cards & Modals:** Standardized on `rounded-2xl` (1rem / 16px) for exercise modules, stat summaries, and workout cards.
- **Interactive Controls & Inputs:** Standardized on `rounded-xl` (0.75rem / 12px) for weight/rep input fields, secondary buttons, and set log strips.
- **Pills & Status Chips:** Fully pill-shaped (`rounded-full`) for set tags (`1RM`, `PR`, `Warm-up`), filter chips, and floating execution pills.

## Components

### Buttons
- **Primary Action ("Finish Workout", "Start Session"):** Height: `56px`. Full width or floating pill. Background: Solid `#2563EB` with text `#F8FAFC`, transitioning to `#00D2FF` background with `#0B111E` text on pressed/active states. Font: `Space Grotesk` 16px bold. Corner radius: `rounded-xl`.
- **Set Completion Trigger (Checkmark CTA):** Height: `44px`, min-width: `52px`. Inactive: Surface `#1A253D` with muted icon `#94A3B8`. Active/Complete: Solid `#10B981` background with white icon check. Provides instantaneous tactile haptic feedback.
- **Ghost/Tertiary Actions ("+ Add Exercise", "Replace"):** Height: `44px`. Transparent background with 1px border `rgba(0, 210, 255, 0.3)`. Text color: `#00D2FF`.

### Exercise & Set Cards
- **Card Anatomy:** Dark navy surface (`#111A2E`), 1px border (`rgba(255,255,255,0.08)`), `rounded-2xl`. Header row includes exercise name, target muscle badge, and an overflow menu.
- **Set Row Grid:** 4-column structured layout:
  1. `Set Number / Tag` (e.g., `1`, `W`, `D`)
  2. `Previous Stat` (Muted monospace value: `100kg x 8`)
  3. `Input Fields` (Weight & Reps grouped with internal `+` / `-` steppers)
  4. `Completion Action` (Target check button)
- **Active Set Row Highlight:** When focused, the set row switches its background to `#1A253D` and gains an inset cyan left border indicator (`3px solid #00D2FF`).

### Input Fields & Steppers
- **Weight & Rep Fields:** Height: `44px`. Monospace typography (`metric-value-md`). Dark input container (`#0B111E`) with subtle border. 
- **Direct Tap Behavior:** Tapping opens a custom bottom numeric keypad with dedicated `+1.25`, `+2.5`, and `+5` quick-add chip selectors for weight plates.

### Chips & Badges
- **Status Badges (PR / Personal Record):** Height: `22px`. Padding: `2px 8px`. Background: `rgba(0, 210, 255, 0.15)`. Border: `1px solid #00D2FF`. Text: `#00D2FF`, uppercase `label-caps`.
- **Set Type Chips (Warmup, Dropset):** Compact rounded badges. Warmup uses Amber (`rgba(245, 158, 11, 0.15)`), Dropset uses Violet (`rgba(168, 85, 247, 0.15)`).

### Rest Timer Overlay
- Floating bottom persistent bar expandable to a full-screen HUD.
- Features large-format timer countdown (`display-timer-mobile`), an automated horizontal cyan progress track (`2px` height across the top edge of the bar), and quick `+30s` / `-15s` adjustment pill triggers.
